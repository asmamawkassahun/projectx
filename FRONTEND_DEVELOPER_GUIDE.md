## Project Overview

This is a sophisticated **AI Agent Platform** built with Next.js 14 that provides both text-based chat and voice interaction capabilities. The application features real-time communication with AI agents that can perform browser automation, web searches, and complex task execution with step-by-step progress tracking.

### Key Application Features:
- **Multi-Modal Interaction**: Text chat and voice conversations with AI agents
- **Real-time Communication**: WebSocket-based live updates during agent operations
- **Browser Automation**: Agents can control browsers and perform web tasks
- **Task Management**: Step-by-step plan generation and execution tracking
- **Session Persistence**: Conversation history and replay functionality
- **File Management**: Upload, view, and download files generated by agents
- **Voice Processing**: Real-time audio streaming and transcription
- **Authentication**: Google OAuth integration with JWT tokens

## Real-time Communication

### Pusher WebSocket Integration

**Connection Management (`src/lib/pusher.ts`):**
```typescript
class PusherManager {
  private _pusher: Pusher;
  private channels: Record<string, Channel> = {};
  private eventListeners: Record<string, Array<(data: any) => void>> = {};
  private sessionId: string | null = null;
}
```

**Event Handling Pattern:**
1. **Connection**: Establish session-based channel
2. **Subscribe**: Listen to specific event types
3. **Process**: Handle incoming events and update UI
4. **Cleanup**: Remove listeners on component unmount

**Key Events:**
- `status_update`: Agent progress updates
- `complete`: Task completion with results
- `error`: Error handling and recovery
- `task_created`: New task initialization
- `in_chat_updates`: Live status messages

### API Communication

**REST Endpoints:**
- `POST /api/session/create`: Create new session
- `POST /api/message/send`: Send chat messages
- `GET /api/task/{uuid}`: Retrieve task history
- `POST /api/agent/stop/{sessionId}`: Stop agent execution

**WebSocket Fallback:**
- Direct WebSocket connection for backup
- Automatic reconnection logic
- Connection status monitoring

### Event Handler Patterns

**Event Registration:**
```typescript
const setupEventListeners = () => {
  pusherManager.addEventListener(PusherEventType.StatusUpdate, handleStatusUpdate);
  pusherManager.addEventListener(PusherEventType.Complete, handleCompleteEvent);
  pusherManager.addEventListener(PusherEventType.Error, handleErrorEvent);

const cleanupEventListeners = () => {
  pusherManager.removeEventListener(PusherEventType.StatusUpdate, handleStatusUpdate);
  pusherManager.removeEventListener(PusherEventType.Complete, handleCompleteEvent);
  pusherManager.removeEventListener(PusherEventType.Error, handleErrorEvent);
};
```
